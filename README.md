# Candy Shop Data Analysis

## Descripción
Proyecto de análisis de ventas de una tienda de dulces usando Python y Pandas.

## Requisitos
- Python 3.x
- Virtualenv

## Instalación

```bash
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

## Ejecución

```bash
python main.py
```
